# 📊 E-Commerce Sales Analysis Dashboard

## 📌 Project Overview

This project presents an interactive E-Commerce Sales Dashboard developed using **MySQL and Microsoft Power BI**.

The objective of this project is to analyse e-commerce sales data and identify key trends and patterns related to **sales performance, customers, products, categories, cities, and customer demographics**.

The dashboard transforms raw transactional data into meaningful business insights that can support data-driven decision-making.

---

## 🎯 Business Questions

This dashboard helps answer the following business questions:

- What is the overall sales performance of the business?
- Which products generate the highest revenue?
- Which products have the highest number of orders?
- Which product categories contribute the most to total sales?
- Who are the top customers based on total sales?
- Who are the top customers based on number of orders?
- Which cities contribute the most to sales?
- How are sales distributed across customer genders?
- Which products have the highest prices?
- How does sales performance change over time?

---

## 🔍 Key Insights

- The business generated approximately **₹2.73M in total sales** from **300 orders**.
- The dataset contains **30 customers**, providing an overview of customer purchasing behaviour.
- The average order value is approximately **₹9.09K**.
- **Laptops** generated the highest revenue among the products shown in the product-level analysis.
- **Furniture** was the highest-performing category by total sales, contributing approximately **₹1.06M**.
- The dashboard identifies the **top 5 customers based on total sales**, helping highlight high-value customers.
- The dashboard also identifies the **top 5 customers based on order volume**, helping understand customer purchase frequency.
- City-level analysis provides insights into differences in sales contribution across locations.
- Gender-based analysis provides an overview of customer sales distribution.
